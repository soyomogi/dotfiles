# grilling 導入先補正

- グリルを始めるとき、回答者をユーザー本人と代理エージェントから選んでもらう。すでに指定があれば、その指定で始める。
- 代理の場合は、質問担当と回答担当を別のエージェントにする。各ラウンドでは代理エージェントに質問し、その回答を待つ。回答担当にはユーザーの目的・制約と委任範囲を伝える。委任範囲内の判断は回答担当が行い、根拠とともに返す。委任範囲が不明な事項や本人の承認・選好が必要な事項は、本人判断として返す。
- 質問担当は代理回答で確定した分岐を進め、本人判断が必要な事項だけを理由と推奨案とともに本人へ提示する。その分岐は本人の回答後に進める。実行前の確認には本体の規則を適用する。
