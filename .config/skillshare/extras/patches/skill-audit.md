# skill-audit 導入先補正

- 対象には、その環境の extras（共通指示・条件付き指示）を全て含める。extras は1つの環境に複数あってもよい。extras 同士、extras と skill の間の重複も判定対象とする。
- 導入先で管理する extras の原本も、監査後の修正対象に含める。
- 指摘は、この導入先で管理する対象についてだけ挙げる。他の管理元が保守する skill 同士・内部の重複は指摘しない。
- この導入先で管理する skill と、他の管理元が保守する skill の間の重複は、管理する側への指摘として挙げる。
- この導入先で管理する skill の目的が、他の管理元の skill と extra の組み合わせで代替可能なら、見直し候補として挙げる。
